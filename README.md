# PhoBo Franchise — Сайт франшизы

Лендинг франшизы сети ресторанов вьетнамской кухни PhoBo: презентация форматов, результатов франчайзи и приём заявок.

**Production:** [franchise.phobo.cafe](https://franchise.phobo.cafe)

## Возможности

- Многосекционный лендинг с анимациями на Framer Motion и каруселями фото форматов
- Форма заявки франчайзи с валидацией: лид уходит в Bitrix24 (`crm.lead.add`), робот шлёт уведомление в Telegram
- Отдельные страницы: меню, оферта, политика конфиденциальности, cookies
- Баннер согласия на cookies
- SEO-инфраструктура: `sitemap.ts`, `robots.ts`, динамический OpenGraph-образ
- Тёмная/светлая тема (next-themes), интеграция аналитики Vercel
- UI на shadcn/ui (Radix UI) с переиспользуемыми компонентами

## Стек

- Next.js 16 (App Router, Turbopack)
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- shadcn/ui (Radix UI)
- react-hook-form + Zod
- Bitrix24 (CRM, через webhook)

## Структура

```
app/              — Страницы, лейауты и API-роуты (заявка, SEO, sub-страницы)
components/       — UI-компоненты и секции сайта
components/ui/    — shadcn/ui примитивы
hooks/, lib/      — хуки и утилиты
public/images/    — Изображения (форматы, партнёры, иконки)
```

## Секции сайта

- **Hero** — главный экран с ключевыми цифрами
- **Концепция** — о бренде PhoBo
- **Сеть** — география присутствия
- **Форматы** — фудкорт/фудхолл и стрит-ритейл с каруселями фото
- **Меню** — позиции меню
- **Преимущества** — что даёт франшиза
- **Результаты франчайзи** — карточки партнёров с фото, выручкой и видео-отзывами
- **Отзывы гостей** — рейтинги на платформах и карточки отзывов
- **Этапы запуска** — шаги открытия точки
- **Контакты** — форма заявки, телефон, email, Telegram

## Запуск

```bash
npm install
npm run dev
```

Сайт доступен на `http://localhost:3000`.

Для отправки заявок в CRM задайте переменную окружения `BITRIX_WEBHOOK_URL` (без неё форма работает, но лид не создаётся).

## Деплой

Сервер: Ubuntu + nginx + PM2

```bash
git pull origin main
npm run build
pm2 restart franchise
```
